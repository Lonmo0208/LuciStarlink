## 3. 下一轮：两件并行的第一优先

### P1（正确性，最高优先）：定位 block 偏差的根因
它是**唯一挡在 storage 模式前面的东西**，也决定"我们的光照与 vanilla 一致"这句结论能不能成立。
要求：
- **只用相邻成对比较**（同一存档、同一探针、连续两次），且只取**无流体气层窄带**；不要再用跨配置跑出来的比例；
- 明确区分三种可能：(a) 我们写的值与 vanilla 不同（我们错）；(b) vanilla 自身在该带不稳定（不是我们错）；(c) 探针/世界重存引入的漂移（测量问题）。
  **判据**：把 (b) 与 (c) 各自排除掉或证明掉，若剩下 (a)，再定位到具体 section/层/单元格并以"逐格差异清单"形式给出；
- 结论以"vanilla 对照 + 相邻成对 + 窄带"三条件齐备的表格呈现。

### P2（性能）：按"更少的轮次 / 更少的工作"推进 `sky_hole`
按你自己写进 ARCH-V2 阶段 2 的结论，依次尝试（每步 per-pass min 中位 ≥5 次）：
- **A1 加长合并窗口**（`publishCoalesceNanos` 可配：250 µs / 500 µs / 1 ms）；
- **A2 减少每轮发布的 section 数**（同 chunk 多 section 合并成一次提交；复核 `skippedIdentical` 空间）；
- **A3 批次入口统一**（每 tick 一波、整批一次 drain，把轮次从"每作业"降到"每 tick"）；
- 三条都不够时，再评估 **B：服务端线程内联"算 + 装"**（必须过"相邻成对探针 0 偏差"门槛）。
判据：per-pass min 中位 ≤ 0.593 ms（追平 SL），或显著下降且 wall / 其余三档不回归。
